# todo-list-v2
A simple Todo list app built with HTML, CSS &amp; JavaScript. Add tasks, delete them one by one, or clear everything at once with Delete All.

Features
- Add a new task
- Delete a single task
- Delete All : removes every task at once

Built With
- HTML
- CSS
- JavaScript

How to Use
1. Type your task in the input box
2. Click Add to put it on the list
3. Click Delete next to a task to remove it
4. Click Delete All to clear the whole list
